# 🌱 Carbon Footprint Analysis – DQN-Based Reinforcement Learning System

> ⚠️ **Proof-of-Concept Project (Later Customized for IoT Devices)**
> This project demonstrates a **Deep Q-Network (DQN)** system designed for **real-time energy monitoring and carbon footprint optimization**. Initially developed in a virtual simulation environment using OpenAI Gym, it was later extended for **IoT-based energy tracking and adaptive control systems**.
> It serves as a demo before the final version is customized and deployed for a client.

---

## 🧠 Overview

The **Carbon Footprint Analysis Agent** is a reinforcement-learning-driven agent built to predict, monitor, and minimize CPU-level energy consumption.
By learning optimal energy behaviors through continuous feedback loops, the system provides actionable insights into **energy efficiency**, **sustainability metrics**, and **hardware optimization** combining environmental awareness with intelligent automation.

---

## 🚀 Core Highlights

* **Deep Q-Network (DQN) Architecture** – Designed and trained a DQN agent using **OpenAI Gym** to simulate CPU energy dynamics and reinforcement learning environments.
* **Real-Time Telemetry** – Integrated data streams to monitor system energy usage, carbon intensity, and temperature variance in real time.
* **Sustainability Analytics Dashboard** – Visualized trends, forecasts, and live metrics for CPU load, energy cost, and carbon output.
* **Self-Improving Agent** – The model continuously learns from feedback to reduce energy spikes and improve long-term efficiency.
* **AI-Driven Recommendations** – Generates actionable suggestions to optimize runtime schedules and hardware utilization.
* **IoT Integration (Client Version)** – Later customized for IoT-enabled devices to allow distributed edge data collection and local optimization loops.

## 💡 Why I Built It

To explore how **reinforcement learning can drive real-world energy efficiency**, enabling systems that don’t just monitor but **actively learn to conserve power**.
The project began as a controlled simulation and evolved into a **proof-of-concept for IoT deployment**, bridging sustainability analytics with agentic AI behavior.

---

## 🎯 Outcome

The result is an intelligent agent capable of **learning optimal energy policies**, cutting unnecessary consumption, and promoting sustainable computing practices.
